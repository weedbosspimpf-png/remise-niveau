# Logo Hortan Intelligence Plus

Version vectorielle redessinée d'après le logo fourni (H or, trait ascendant, étoile).

- `hortan-symbole.svg` : le symbole seul, vectoriel (toutes tailles, impression).
- `png/` : fonds transparents. `-clair` = texte clair pour fond sombre, `-sombre` = pour fond clair.
- `logo.html` + `render-logo.mjs` : source et export (`node render-logo.mjs`).
- `propositions/` : anciennes pistes A/B/C (non retenues).
