# Site Hortan Intelligence Plus (une page)

Fichiers à mettre en ligne : `index.html`, `pub-hortan.mp4`, `pub-hortan.jpg`, `hortan-symbole.svg`.

## Mise en ligne gratuite (Netlify, ~2 min)
1. Aller sur https://app.netlify.com/drop (créer un compte gratuit).
2. Glisser-déposer **le dossier `site`** entier dans la page.
3. Le site est en ligne sur une adresse `xxx.netlify.app` ; on peut la renommer
   (Site settings → Change site name), par ex. `hortan-intelligence.netlify.app`.
4. Plus tard : brancher un nom de domaine acheté (Domain settings).
